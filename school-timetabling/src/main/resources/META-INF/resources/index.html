      How to use VTC AI Timetabling Utility

      Follow this guide to try a sample timetable, prepare your own data, generate a schedule, make adjustments, and ask the Timetable Agent for help.

      Fastest start: choose a dataset from Sample Data, open AI Scheduler, and select Solve.
      Quick start with sample data
      1
      Load a sample. Open Sample Data in the top-right corner and choose a dataset.
      2
      Review settings. In AI Scheduler, optionally enable soft constraints and set their priority weights.
      3
      Generate the timetable. Select Solve. Select Stop solving if you need to end the process early.
      4
      Inspect the result. A feasible schedule has no hard-constraint violations. Switch between By room, By teacher, By student group, and Parallel.
      Prepare your own data
      1
      Set up the school week. In Preparation, enter a dataset name, choose weekdays and school hours, and set an ECA period if required.
      2
      Add resources. Create subjects, classrooms, teachers, and student groups.
      3
      Define eligibility. Select which subjects apply to each student group, teacher, and classroom in Subject assignments.
      4
      Create lessons. Add subject cards manually or select Generate to build them from the assignments.
      5
      Move data between Preparation and the scheduler. On Preparation, select Save, then on AI Scheduler use Load or Upload in the subject-cards group. After editing cards in the scheduler, select Save or Download there so Preparation can load them from cache or file.
      Solve, review, and adjust
      • Soft constraints: check the preferences you want before solving. A higher weight gives that preference more influence.
      • Scores: hard violations must reach zero for a feasible timetable. Use the ? button for an explanation.
      • Violation details: select a highlighted lesson card to see the broken constraint and related lessons.
      • Manual assignment: drag a lesson from Unassigned into an available timetable slot.
      • Edit an unassigned card: select the pencil button next to Remove to change subject, teacher, duration, rooms, and related fields.
      • Protect an assignment: pin a placed lesson so a later solve keeps it in that timeslot. Unpin it when changes are allowed.
      • Remove an assignment: return a placed lesson to Unassigned, then place it again or solve the timetable.
      Save and explore the timetable
      • In the indigo Timetable group, select Save to store the current timetable project in browser cache, or Load to restore it later.
      • In the same group, select Download to save the timetable project as a JSON file, or Upload to restore one.
      • Select Clear in the Timetable group to remove all lessons from the current timetable.
      • In the amber Subject cards group, select Save or Download to send the current cards back to the Preparation tab (cache or file).
      • Use View weekday to open a focused day view in a separate window.
      • Use Apply filter to find common free periods or explore replacement options.
      • Save a full Preparation workspace when you want to preserve both setup data and subject cards for later editing.
      Use the Timetable Agent
      1. Start the chat-agent service and confirm that the toolbar shows Agent: online.
      2. Select the model badge to configure the active LLM provider when required.
      3. Open Show guide & examples, choose an example prompt, or type your own request.
      4. Ask the agent to load data, solve a timetable, check constraints, find common free periods, or suggest replacement teachers.
      5. Select View in chat to inspect a result, or Open in Demo UI to continue editing it in AI Scheduler.

      Example requests

      • Load dataset1 and solve it.
      • Check the timetable for constraint violations.
      • Find common free timeslots for these teachers.
      • Find a replacement teacher for Tuesday.

      Troubleshooting

      • If the web page is unavailable, confirm that the timetable backend is running on port 8080.
      • If the Timetable Agent is offline, start the chat-agent service on port 3001.
      • If the agent is online but cannot answer, verify the selected LLM provider, model name, server URL, and required API key.
      • If solving cannot continue, check for missing teachers, student groups, eligible classrooms, or invalid lesson durations in Preparation.

      如何使用 VTC AI 排課工具

      按照本指南，您可以試用範例課表、準備自己的資料、產生課表、 進行調整，並向 Timetable Agent 尋求協助。

      最快開始：從 Sample Data 選擇資料集， 開啟 AI Scheduler，然後按 Solve。
      使用範例資料快速開始
      1
      載入範例。開啟右上角的 Sample Data 並選擇資料集。
      2
      檢視設定。在 AI Scheduler 中，可選擇啟用軟性限制並設定優先權重。
      3
      產生課表。按 Solve。如需提前結束，可按 Stop solving。
      4
      檢視結果。可行的課表沒有硬性限制違規。可在 By room、By teacher 及 By student group 之間切換。
      準備您自己的資料
      1
      設定上課週。在 Preparation 中輸入資料集名稱、選擇上課日及時間，並設定 ECA 時段（如需要）。
      2
      新增資源。建立科目、課室、教師及學生組別。
      3
      定義適用範圍。在 Subject assignments 中，為每個學生組別、教師及課室選擇適用的科目。
      4
      建立課程。手動新增科目卡，或按 Generate 從設定自動產生。
      5
      在 Preparation 與排課器之間傳送資料。在 Preparation 按 Save，然後在 AI Scheduler 的 subject cards 群組按 Load 或 Upload。在排課器編輯科目卡後，按 Save 或 Download，即可讓 Preparation 從快取或檔案載入。
      求解、檢視及調整
      • 軟性限制：求解前勾選所需偏好。權重越高，對課表的影響越大。
      • 分數：硬性違規必須為零才能達成可行課表。按 ? 按鈕查看說明。
      • 違規詳情：點選高亮課程卡查看違反的限制及相關課程。
      • 手動分配：將課程從 Unassigned 拖曳至可用時段。
      • 編輯未分配科目卡：按移除按鈕旁的鉛筆圖示，即可更改科目、教師、時數、課室等資料。
      • 保護分配：釘選已放置的課程，使後續求解保留該時段。需要更改時取消釘選。
      • 移除分配：將已放置課程退回 Unassigned，再重新放置或求解。
      儲存及探索課表
      • 在靛藍色 Timetable 群組按 Save 將目前課表專案存入瀏覽器快取，或按 Load 還原。
      • 在同一群組按 Download 將課表專案存成 JSON 檔，或按 Upload 還原。
      • 在 Timetable 群組按 Clear 清除目前課表的所有課程。
      • 在琥珀色 Subject cards 群組按 Save 或 Download，即可將目前科目卡傳回 Preparation 分頁（快取或檔案）。
      • 使用 View weekday 在新視窗開啟專注的日視圖。
      • 使用 Apply filter 尋找共同空堂或探索代課選項。
      • 儲存完整的 Preparation workspace 以保留設定資料及科目卡供日後編輯。
      使用 Timetable Agent
      1. 啟動 chat-agent 服務，確認工具列顯示 Agent: online。
      2. 按模型標籤設定所需的 LLM 提供者。
      3. 開啟 Show guide & examples，選擇範例提示或輸入自己的請求。
      4. 請 Agent 載入資料、求解課表、檢查限制、尋找共同空堂或建議代課教師。
      5. 按 View in chat 檢視結果，或按 Open in Demo UI 在 AI Scheduler 繼續編輯。

      疑難排解

      • 若網頁無法使用，確認排課後端正在 port 8080 運行。
      • 若 Timetable Agent 離線，在 port 3001 啟動 chat-agent 服務。
      • 若 Agent 在線但無法回應，檢查所選 LLM 提供者、模型名稱、伺服器 URL 及 API 金鑰。
      • 若無法繼續求解，檢查 Preparation 中是否缺少教師、學生組別、適用課室或無效的課程時長。

      LLM model setup

      Your LLM settings are stored only in this browser (localStorage). They are sent to the chat-agent with each message but are not saved on the server.

      Chat agent is offline — start it with cd chat-agent; npm run dev before sending messages.
